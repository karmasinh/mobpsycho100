# Documentación del software base

Esta carpeta contiene la documentación funcional común del backend y la historia de fases del sistema. Es una fuente técnica de referencia, no sustituye las especificaciones separadas de Luciana y Alison.

- [`DOCUMENTACION.md`](DOCUMENTACION.md): funcionalidades implementadas por fases, actores, flujos, reglas y roadmap histórico.
- [`fase2.md`](fase2.md): decisiones y alcance de cierre de caja y tiempo real.
- [`backend-compartido.md`](backend-compartido.md): estado actual del backend y brechas verificadas.
- [`casos-compartidos.md`](casos-compartidos.md): casos del core común de autenticación, RBAC, sucursal, WebSocket y auditoría.

Las especificaciones por proyecto están en [`../../../Luciana Docs/`](../../../Luciana%20Docs/) y [`../../../Alison Docs/`](../../../Alison%20Docs/). Los cambios deben reflejarse en el proyecto correspondiente y enlazarse con los casos `CU-L-*` o `CU-A-*`.
