El control de inventario es esencial para la operación de cualquier restaurante.
Desde este módulo podemos ver el stock disponible de insumos en la sucursal, incluyendo sus lotes y fechas de vencimiento.
Cuando un insumo se daña o se pierde por algún motivo, registramos una merma, indicando el insumo, la cantidad y el motivo.
Esto mantiene el inventario siempre actualizado y ayuda a identificar problemas recurrentes de desperdicio.
