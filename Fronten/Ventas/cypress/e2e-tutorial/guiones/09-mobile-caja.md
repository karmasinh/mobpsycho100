El sistema también funciona perfectamente desde un celular o una tablet, gracias a que está construido con un diseño adaptable.
Aquí vemos la pantalla de Caja en una vista móvil, con el mismo flujo que ya conocemos: seleccionar platos, armar el pedido y cobrar.
Esto es útil para sucursales pequeñas o para el personal que necesita atender desde un dispositivo móvil sin perder ninguna funcionalidad del sistema.
