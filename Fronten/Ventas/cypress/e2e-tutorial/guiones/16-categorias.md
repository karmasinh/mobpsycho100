# Guion — 16. Categorías de Plato

En esta pantalla el administrador organiza el menú por categorías, por ejemplo Almuerzos, Bebidas o Antojos de la tarde. Hacemos clic en "+ Nueva" y se abre una ventana pequeña donde escribimos el nombre de la categoría y, opcionalmente, una descripción corta. Guardamos y la nueva categoría aparece como una tarjeta más en la cuadrícula, marcada como "Activo". Para editarla, la buscamos con el buscador de arriba, entramos con "Editar" y cambiamos el nombre para mostrar que el sistema actualiza la tarjeta al instante. Después mostramos la baja: al presionar "Baja" y confirmar, la categoría no se elimina de la base de datos, solo se desactiva, así que la tarjeta se queda visible pero atenuada, con la etiqueta "Inactivo". Esto es importante porque una categoría inactiva ya no aparece disponible en el menú de ventas, pero los platos que ya la usaban en el historial no se pierden. Como último detalle, notamos que el sistema incluso permite reactivarla más adelante con el botón "Alta" si el administrador se equivocó o cambia de opinión.
