Para cerrar el recorrido por el módulo de Ventas, veamos la funcionalidad de facturación electrónica.
Primero configuramos los datos fiscales del negocio, que son necesarios para poder emitir comprobantes válidos.
Luego, sobre una venta ya registrada, podemos emitir la factura correspondiente directamente desde el sistema.
Esta base de facturación electrónica prepara al sistema para cumplir con los requisitos normativos de forma integrada con el resto del proceso de venta.
