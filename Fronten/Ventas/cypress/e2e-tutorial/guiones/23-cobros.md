# Guion — 23. Cobros

Ahora vemos la pantalla de Cobros mensuales, que usa el cajero para cobrar la mensualidad de los pensionados. Por defecto se muestra solo la vista de pendientes, es decir, los pensionados que todavía deben algo este mes, y arriba tenemos unas tarjetas con el total pendiente y cuántos ya pagaron. Buscamos al pensionado que queremos cobrar y le damos clic a registrar pago. Se abre una ventana con el saldo que debe, ya precargado como monto sugerido, y elegimos la forma de pago, en este caso QR. Confirmamos el pago y el sistema nos avisa que quedó registrado correctamente. Si el pensionado pagó todo lo que debía, su fila cambia a estado pagado; si pagó solo una parte, queda marcado como pago parcial con el saldo restante actualizado. También podemos cambiar a la vista de todos los cobros para ver el historial completo, no solamente los pendientes.
