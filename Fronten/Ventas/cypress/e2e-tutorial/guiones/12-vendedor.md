# Guion — 12. Rol Vendedor

Ahora vamos a iniciar sesión como vendedor2, un usuario con el rol de Vendedor, para mostrar el flujo diario de trabajo en este puesto. En el Dashboard vemos que la pantalla es bien simple: solo los datos generales del día, sin ninguna sección de inteligencia de negocio, porque esos gráficos están reservados para el administrador y el gerente de sucursal. Antes de vender, abrimos el turno de caja con un monto inicial, ya que el sistema no deja cobrar sin un turno abierto. Entramos a Caja y armamos un pedido con dos productos reales de la carta: un Licuado de papaya y una Agua mineral. Vemos cómo el total se actualiza automáticamente, escribimos el monto recibido en efectivo y el sistema calcula el vuelto al instante, antes incluso de confirmar el cobro. Confirmamos la venta y aparece el ticket de éxito con el total y el vuelto correctos. Después vamos a Historial de ventas: el menú sí muestra ese enlace, pero al presionar Buscar el sistema nos avisa que no se pudo cargar el historial, porque el rol Vendedor en realidad no tiene permiso para consultar esa lista en el backend, solo para vender. Finalmente revisamos la pantalla de Pedidos, donde el vendedor puede ver el estado de cada pedido —pendiente, en cocina, listo, entregado o cancelado— y abrir el detalle de cualquiera de ellos para revisar los platos y el total.
