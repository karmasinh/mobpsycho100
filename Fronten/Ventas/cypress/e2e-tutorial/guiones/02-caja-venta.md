Ahora vamos a registrar una venta desde la Caja, que es el corazón del trabajo diario del cajero.
El cajero inicia sesión con su propio usuario, y se dirige al módulo de Caja.
Aquí seleccionamos los platos del menú que el cliente desea, incluyendo el Saice, uno de nuestros platos bandera tarijeños.
Podemos agregar dos o tres platos al pedido, y el sistema va calculando el total automáticamente.
Una vez armado el pedido, seleccionamos la forma de pago, en este caso efectivo, y confirmamos el cobro.
El sistema genera el ticket de venta, que es el comprobante que se le entrega al cliente.
Así de simple y rápido se registra una venta en el mostrador.
