# Guion — 22. Aprobaciones

En esta parte mostramos cómo funciona el flujo de aprobaciones para anular una venta. Primero entramos como cajero y registramos una venta normal en la Caja, con un plato real del menú. Después vamos al Historial de ventas, ubicamos esa venta recién cobrada y hacemos clic en el botón de solicitar anulación, porque el cajero ya no puede anular directamente como antes: ahora tiene que pedir permiso. Escribimos el motivo, por ejemplo que el cliente se equivocó de pedido, y enviamos la solicitud. El sistema nos avisa que queda pendiente de aprobación de un administrador, y si vamos a la pantalla de Aprobaciones como cajero, ahí vemos nuestra propia solicitud en estado pendiente. Ahora cambiamos de usuario y entramos como administrador. En su pantalla de Aprobaciones aparece la solicitud del cajero esperando revisión, con el motivo que escribió. El administrador la aprueba con un clic, el sistema aplica la anulación de la venta automáticamente, y la solicitud ya no aparece más entre las pendientes.
