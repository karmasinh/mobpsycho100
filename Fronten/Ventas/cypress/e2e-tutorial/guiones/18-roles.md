# Guion — 18. Roles y Permisos

Ahora entramos a la pantalla de Roles y Permisos, una sección que solo el administrador puede ver. Aquí se define qué módulos del sistema puede usar cada rol. Hacemos clic en "+ Nuevo rol" y se abre un formulario donde escribimos el nombre del rol y una breve descripción. Debajo aparece la lista de módulos disponibles, marcamos uno con su casilla para darle acceso a ese rol y presionamos "Guardar". El nuevo rol aparece de inmediato en la lista con el módulo que le asignamos. Después probamos la edición: buscamos el rol recién creado, entramos con "Editar" y le agregamos un segundo módulo, simulando que le damos más permisos a ese rol. Guardamos y confirmamos que ahora tiene dos módulos asignados. Por último mostramos la baja: al presionar "Baja" y confirmar, el rol no se borra del sistema, solo queda marcado como "Inactivo" y ya no se puede asignar a nuevos usuarios, pero su historial se conserva.
